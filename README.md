# Number Guessing Game

Project for the **freeCodeCamp Relational Database Certification**. A CLI number guessing game built with Bash and PostgreSQL.

## Files
- `number_guess.sh` - Main Bash game script.
- `number_guess.sql` - PostgreSQL database dump.

## How to Run
```bash
psql -U postgres < number_guess.sql
chmod +x number_guess.sh
./number_guess.sh
```
